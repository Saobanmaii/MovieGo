# MovieGo — Admin console UI kit
Operations console for cinema staff. Composes `StatCard`, `BarList`, `DataTable`, `Badge`, `Switch`, `DateStrip`, `Dialog`, `Toast` from the system.

Pages: Dashboard (KPIs, revenue by movie, tonight's showtimes) · Movies (catalogue table, Add-movie dialog → toast) · Showtimes (date strip, filters, occupancy bars, on-sale switches) · Cinemas · Revenue reports.
Files: `Sidebar.jsx` (also PageHead + Panel), `Dashboard.jsx`, `Movies.jsx`, `Showtimes.jsx` (also Cinemas, Reports), `data.js`.

Original design — no existing admin screens were supplied. Same dark foundations as the customer app, denser: 14px body, tables over cards.
