# MovieGo — Customer web app UI kit
Click-through recreation of the moviegoer booking flow, composed from the design-system components (`window.MovieGoDesignSystem_a2f949`).

Screens: `Home.jsx` (hero + Now showing rows, genre chips) → `MovieDetail.jsx` (backdrop, date strip, showtimes per cinema, sticky continue bar) → `SeatSelect.jsx` (SeatMap + BookingSummary) → `Payment.jsx` (simulated checkout, leave-flow Dialog) → `Confirmation.jsx` (ticket stub) and `Bookings.jsx` (history).
Shared: `Header.jsx`, `Backdrop.jsx` (key-art placeholder), `data.js` (sample films, cinemas, bookings — fictional).

No production code or screens were supplied — this kit is an original design built on the system's foundations. Posters and backdrops are typographic placeholders; drop in real key art via `MoviePoster src`.
