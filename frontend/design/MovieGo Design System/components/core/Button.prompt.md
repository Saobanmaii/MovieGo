Pill-shaped action button; primary (red) for the single most important action in a view — "Book tickets", "Continue", "Pay".
```jsx
<Button iconLeft="ticket">Book tickets</Button>
<Button variant="secondary" iconLeft="play">Trailer</Button>
```
Variants: primary · secondary · outline · ghost. Sizes sm/md/lg. Hover lightens + red glow; press scales to .97.
