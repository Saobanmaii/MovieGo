Lucide icon wrapper — use for every UI glyph; never emoji or hand-drawn SVG.
```jsx
<Icon name="ticket" size={18} />
```
Needs `<script src="https://unpkg.com/lucide@0.468.0/dist/umd/lucide.min.js"></script>` loaded before the bundle. Stroke 1.75, inherits currentColor. Fill a star for ratings with `fill="currentColor"`.
